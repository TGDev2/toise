# Relecture métier des sept listes d'achat

## Pourquoi ce document

Toisé calcule des listes d'achat pour sept types de travaux courants du
second œuvre. Ce document présente un exemple chiffré pour chacun, avec la
raison de chaque quantité. Vous n'avez pas à ouvrir le logiciel : lisez une
ou plusieurs pages, sur le métier que vous connaissez, et dites si vous
achèteriez cette liste sur un chantier comme celui décrit.

On ne vous demande pas si l'idée est bonne, mais si le chiffre est juste.
Une quantité qui vous semble fausse, un produit qui manque, une habitude de
chantier qu'on n'a pas eue : c'est exactement ce qu'on cherche. Ce document
remplace un essai sur un vrai chantier, qu'on n'a pas fait — vos annotations
sont la seule vérification de terrain que ces chiffres reçoivent avant
d'être montrées à un client.

Trois questions ferment chaque page ; il y a de la place pour écrire dessus.
